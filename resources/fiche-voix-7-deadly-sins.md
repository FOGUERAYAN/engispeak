# Fiche mémo : la voix (Semaine 1, Session 3 – Julian Treasure)

Les 7 péchés à éviter : gossip, judging, negativity, complaining, excuses, exaggeration, dogmatism.
Les fondations (HAIL) : Honesty, Authenticity, Integrity, Love.

Les outils vocaux :
- **Pitch** : varie la hauteur pour souligner une idée.
- **Volume** : baisse la voix pour capter l'attention, pas seulement l'élever.
- **Timbre** : parle depuis la poitrine, pas depuis la gorge.
- **Pace** : ralentis sur l'idée clé, pause de 2–3 secondes avant l'argument.
